# DuckLog

> **Main Feature:** The Weekly Summary View lets you instantly see what you've accomplished this week—perfect for 1:1s with your manager or team meetings.

DuckLog is a multiplatform journaling app built for developers, inspired by the Day One journal macOS app. It allows you to quickly log entries about your daily tasks, code reviews, and blockers, while supporting GitHub PR linking and customizable summaries for one-on-one meetings.

**The core workflow is designed around the Weekly Summary View, making it easy to prepare for your weekly check-ins and communicate your progress.**

## Current Focus

- macOS as the primary platform (iPad and iOS support planned)
- SwiftUI-based user interface with a sidebar, entry list, and detail/editor pane (Day One-inspired design)
- Markdown-based local storage
- Streamlined journaling and weekly review workflow

## Planned Features

- GitHub API integration
- AI-powered summary generation
- Enhanced multiplatform support (iPad and iOS)
